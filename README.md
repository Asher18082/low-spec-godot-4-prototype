# Low-spec Godot 4.7 Prototype

This repository contains a minimal Godot 4.7 project demonstrating:
- 3D player movement (WASD + Space to jump)
- Collectable items (Area3D)
- Door opening after enough items collected
- HUD showing score

How to run:
1. Download or clone the repo
2. Open project.godot with Godot 4.7
3. Ensure Input Map contains move_forward(W), move_back(S), move_left(A), move_right(D), jump(Space)
4. Run the project (F5)

If something doesn't work, enable Debug -> Visible Collision Shapes to check collisions.
